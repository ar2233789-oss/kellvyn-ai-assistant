# First brain experiments (proposed, not executed)

Create an experiment with the Studio CLI, then define controls, metrics, repetitions and acceptance criteria before recording results.

1. brain-attention-numerics — verify attention/masking and gradients on deterministic tiny tensors.
2. brain-kv-cache-equivalence — compare cached and full-prefix decoding logits/token by token.
3. brain-tokenizer-roundtrip — test encode/decode invariants, byte fallback and corpus coverage.
4. brain-protocol-compliance — measure KELLVYN/1 termination, malformed output and tool schema compliance.
5. brain-portuguese-generalization — score held-out Portuguese tasks with independent oracles.
6. brain-poco-f6-profile — measure latency, throughput, PSS/heap, thermal behavior and battery on the physical device.

No experiment above has been run. They are the initial queue, not claimed results.
