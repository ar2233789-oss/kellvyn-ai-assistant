# Kellvyn — execução e distribuição privada

- Proprietário: uso exclusivo do usuário.
- Não existe objetivo de publicação pública ou listagem em loja.
- O sistema deverá poder ser compilado e instalado manualmente como APK nativo no Poco F6.
- Conversa, memória e projetos ficam no armazenamento privado do aplicativo por padrão.
- Rede 5G/Wi‑Fi serve para navegação e obtenção de conteúdo quando o usuário habilitar, não como dependência obrigatória para inferência.
- Não exigir conta de provedor de IA, chave de API paga ou hospedagem externa para a operação central.
- Modelos, bibliotecas e dados ainda precisam ter origem e termos de uso documentados; uso privado não equivale a autoria.
- Credenciais de bots devem permanecer em armazenamento seguro e não aparecer em logs, prompts, exports ou backups sem proteção.
- Recursos que controlem outros apps/dispositivo deverão explicitar permissões Android, escopo, riscos, botão de interrupção e evidência de execução.
- Nenhuma versão deve ser chamada de funcional sem build, instalação e testes no aparelho real.

O repositório de distribuição antigo permanece intocado. Qualquer decisão futura sobre tornar repositório ou artefato público deverá vir do proprietário.
